# TwoStepCreateWorld

点击「单人游戏」时始终进入世界列表界面，即使当前没有任何世界。

同时支持 Fabric 与 NeoForge，兼容 Minecraft 26.1、26.1.1 和 26.1.2。

若有旧版本需要，请优先查看模组 [F**k Create World](https://www.curseforge.com/minecraft/mc-mods/f-k-create-world) 与 [OWorld2Create](https://www.curseforge.com/minecraft/mc-mods/oworld2create) 是否支持，如果不支持，请提出issue

# TwoStepCreateWorld

Clicking “Singleplayer” always opens the world list screen, even when there are currently no worlds.

It supports both Fabric and NeoForge, and is compatible with Minecraft 26.1, 26.1.1, and 26.1.2.

If you need an older version, please first check whether the mods [F\*\*k Create World](https://www.curseforge.com/minecraft/mc-mods/f-k-create-world) and [OWorld2Create](https://www.curseforge.com/minecraft/mc-mods/oworld2create) support it. If they don’t, please open an issue.
